# Form / Function — public repository design gallery

Open `index.html` locally or serve this folder with `python -m http.server 8000` and open `http://localhost:8000/`. This gallery contains **only 18 public repository records** and copies of public showcase assets. Its `data.js` has no private repository entries, names or screenshots. Keep the private sister gallery in its separate private repository.

Entries marked **ON VIEW** link to working, independently accessible local prototypes under `showcases/<repository>/index.html`. The browser screenshots on their cards were captured from these implemented pages. Entries marked **IN PROGRESS** are inventory only and do not claim a design, screenshot, remote branch, or public hosted URL.

The registry is `data.js`: category, purpose, style, palette, font pair, state, path and branch/commit links. Source review is still pending for records not marked completed. No production deployment is configured; a GitHub branch URL is not a public site URL.
