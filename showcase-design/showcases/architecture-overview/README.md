# System Atlas — design-only architecture showcase

Open `index.html` directly or run `python -m http.server 8000` from this folder and visit `http://localhost:8000/`. No dependencies are installed. The interactive map uses static local descriptions and makes no API requests.

**Evidence:** [`ARCHITECTURE.md`](../ARCHITECTURE.md) is the repository's sole starting file (`1d312d2b`). It describes a proposed multi-service architecture. This showcase deliberately labels every diagram as a reference design, not a working deployment, and makes no traffic, performance or security certification claims. The page simplifies the documented diagram; the linked source contains the full detail.

**Art direction:** cartographic editorial reading room; paper-white grid, red annotation accents, pale cyan selected layers; Newsreader display + IBM Plex Sans/Mono. Flat borders, oversized serif typography and interactive architecture map distinguish it from the other showcase designs.
