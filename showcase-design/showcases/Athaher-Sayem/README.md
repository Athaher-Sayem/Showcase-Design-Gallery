# Athaher Sayem — standalone public-profile showcase

Open `index.html` directly or run `python -m http.server 8000` from this folder. This is an independent profile-homepage design based only on the existing public `README.md` at starting `main` commit `f41b5abee0f200553ccc667625cd1e01b39ae5df`. The source is a GitHub profile repository, not an application. Descriptions of education, interests, listed languages, learning areas and links are attributed to that README; this page does **not** claim that its older goals, skills, employment or results have been independently confirmed today.

The category switcher is local static content; no GitHub statistics, social feeds or external data are queried. Contact links are copied from the README. The oversized A/S monogram is CSS typography, not an actual portrait. No original README content or main-branch file is edited.

Direction: personal editorial poster on mineral paper, oxford-blue letterforms, acid peach punctuation; Syne display, DM Sans paragraphs and IBM Plex Mono context labels.
