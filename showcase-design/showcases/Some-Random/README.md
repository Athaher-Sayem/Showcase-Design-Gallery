# Scratchpad / C++: standalone homepage

Subject: A compact shelf of standalone C++ exercises on lists, linked lists and comparisons.

Direction: brutal. The page uses source-backed navigation and does not call the original app backend. References: `class greater`, `linklist palindrom`, `list find next and prev`. This homepage does not compile or execute code.

Only `showcase-design/` is new in this repository. Responsive screenshots: `assets/screenshots/desktop.png`, `tablet.png`, `mobile.png`.
